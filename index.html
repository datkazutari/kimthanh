How the assistant processes a request

  1. Identify the task.

    Route the message to IELTS practice, a general question, or an image summary.

  2. Set up IELTS practice.

    Ask for Academic, General Training, or one skill; the conversation shown proceeds with Speaking.

  3. Ask a practice question.

    Start with a prompt such as the Part 1 hometown question shown in the chat.

  4. Respond to other requests.

    Explain a concept with an example, or summarize the visible details in a shared image.

  5. Continue the practice loop.

    After the user answers, provide feedback and an estimated band, then offer the next question.

What the assistant returns

Image summary

Conversation follow-up
